# yc-shorts — Why Bhai

Faceless Hindi YouTube Shorts: how everyday things work, in 3D. Each post is planned in
markdown, generated entirely in Higgsfield (text-to-video clips that carry their own Hindi
narration and SFX) and edited in CapCut. No ChatGPT stills in the video, no ElevenLabs (dropped
2026-11-17). The thumbnail is the one image made in ChatGPT (Hinglish text, `playbook/thumbnail.md`).

## Read first, instead of re-researching
- `NICHE.md` — channel look, colours, typography, YouTube metadata and title rules
- `playbook/` — reusable how-to: story formula and per-clip Hindi VO word budget, Higgsfield
  clip rules and prompt template (picture + voice), ChatGPT thumbnail prompt, mechanism-research method,
  post README template
- `SUGGESTED_IDEAS.md` — do-not-repeat list: exclude these when suggesting ideas, and log new ones there
- `PUBLISHED.md` — what's live: links, titles used, and stats at 24 h / 7 d / 28 d, plus lessons learned
- `INSTAGRAM_FACEBOOK.md` — Instagram + Facebook Page setup and the Reel routine for every post
- `posts/<slug>/` — one folder per Short: `README.md` (story, script, prompts) and `youtube.md` (upload fields)

## Keep it reusable
- Anything learned that applies beyond one object (tool behaviour, pacing, what worked or
  failed, prompt tweaks) goes into the matching `playbook/` file. Log tool runs in
  `playbook/grok-imagine-higgsfield.md` → *Run notes*.
- Object-specific facts and sources stay in that post's README (*Mechanism check*).
- Tool facts carry a "checked" date. Re-check only when something looks off.
